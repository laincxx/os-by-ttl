# os-by-ttl
Python-скрипт для определения операционной системы.
TTLFinger: эвристическое определение ОС по TTL (Time To Live)

Простой Python‑скрипт для предварительной оценки операционной системы удалённого узла по значению TTL из ICMP‑ответа (ping). Инструмент полезен для быстрой сетевой разведки и обучения принципам фингерпринтинга.

## Таблица эвристических значений TTL

При прохождении каждого маршрутизатора (хопа) значение **TTL** уменьшается на `1`. Скрипт анализирует полученное значение и сопоставляет его со стандартными начальными параметрами разных операционных систем:

| Полученный TTL | Начальный TTL | Вероятная ОС / Устройство |
| :--- | :--- | :--- |
| **1 – 64** | `64` | Linux, macOS, Android, iOS, FreeBSD |
| **65 – 128** | `128` | Windows (Desktop / Server) |
| **129 – 255** | `255` | Сетевое оборудование (Cisco IOS, маршрутизаторы), Solaris |

> **Примечание:** Определение ОС по TTL носит **эвристический (ориентировочный)** характер. Администраторы могут вручную менять стандартное значение TTL в настройках ядра, а крупные облачные и Anycast-сервисы (например, `8.8.8.8`) иногда используют нестандартные значения, из-за чего Linux-сервер может определяться как Windows.
